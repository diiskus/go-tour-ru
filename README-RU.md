# Tour of Go (Русская версия)

Официальный интерактивный тур по языку программирования Go от The Go Authors, полностью переведённый на русский язык.

Включает все современные разделы Go (в том числе дженерики и актуальную модель многопоточности).

---

## Содержание тура

1. **Добро пожаловать (`welcome.article`)** — как пользоваться туром, навигация, запуск примеров кода.
2. **Основы языка (`basics.article`)** — пакеты, функции, переменные, базовые типы, преобразования типов, константы.
3. **Управление потоком выполнения (`flowcontrol.article`)** — циклы `for`, условия `if/else`, оператор `switch`, отложенный вызов `defer`.
4. **Сложные типы (`moretypes.article`)** — указатели, структуры, массивы, срезы (slices), ассоциативные массивы (maps), замыкания функций.
5. **Методы и интерфейсы (`methods.article`)** — методы, получатели значений и указателей, интерфейсы, утверждения и переключатели типов, ошибки, Reader, изображения.
6. **Дженерики (`generics.article`)** — параметры типов, ограничения (comparable), обобщенные структуры данных.
7. **Многопоточность / Конкурентность (`concurrency.article`)** — горутины, каналы, буферизация, `select`, `sync.Mutex`, упражнения на обход бинарных деревьев и веб-краулер.

---

## Как запустить тур локально

### Вариант 1. Запуск готового бинарника

В папке `tour/` уже собран исполняемый файл:

```bash
cd ~/Проекты/go-tour-ru/tour
./tour-ru
```

После запуска браузер автоматически откроет тур по адресу: `http://127.0.0.1:3999`.

### Вариант 2. Запуск через Go

```bash
cd ~/Проекты/go-tour-ru/tour
go run .
```
